# Rishard Dukes — Portfolio v2

A complete repositioning of the portfolio from a code-project gallery to a professional IT Operations, Asset Management, endpoint support, and automation site.

## Local development

```bash
npm install
npm run dev
```

## Deploy through the existing Vercel project

Replace the matching files in the GitHub repository, commit, and push to `main`. Vercel should automatically build and publish the new version if the repository remains connected.
